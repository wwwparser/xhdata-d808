# XHDATA D-808 — справочный сайт

Сайт для владельцев приёмника XHDATA D-808 в Москве и Подмосковье: инструкция простыми словами,
все диапазоны и как в них ловить, что слушать (FM / СВ / ДВ / КВ / служебный эфир) с подсказкой
«какие кнопки нажать» у каждой станции, онлайн-эфир 93 станций, программа на день и вечер,
радиолюбители и радиохулиганы, антенны до 3000 ₽ с Wildberries (только товары с >10 отзывами,
с фото и выжимкой отзывов).

**Сайт:** https://wwwparser.github.io/xhdata-d808/

## Публикация

GitHub Pages через GitHub Actions (`.github/workflows/pages.yml`): каждый push в `main` пересобирает
данные скриптом `build_data.py` и выкладывает папку `site/`. Чтобы обновить сайт, достаточно поправить
`data/*.json` и сделать push.

## SEO

- `scripts/seo.py` — title/description/canonical/Open Graph, JSON-LD (BreadcrumbList, WebSite, TechArticle,
  FAQPage, DigitalDocument, ItemList с BroadcastService и Product), блок «Частые вопросы» (`data/faq.json`),
  `sitemap.xml` и `robots.txt`. Адрес сайта — `SITE_URL`; при переезде на свой домен:
  `SITE_URL=https://домен/ python scripts/seo.py`.
- `scripts/prerender.py` — в GitHub Actions каждая страница сохраняется уже отрисованной (таблицы и тексты
  в HTML), публикуется папка `dist/`. Исходники в `site/` не меняются.
- `scripts/indexnow.py` — после публикации отправляет Яндексу список страниц по IndexNow (заявка на переобход).
  Ключ — файл `site/<ключ>.txt`.
- Корень хоста — репозиторий `wwwparser/wwwparser.github.io`: там `robots.txt` со ссылкой на наш sitemap
  и файл подтверждения Яндекс.Вебмастера.

## Как открыть прототип

Двойной клик по `site/index.html` — сайт работает прямо с диска, без сервера и сборщика.

После правки данных в `data/*.json`:

```
python scripts/build_data.py   # data/*.json -> site/data/*.js + проверка данных
python scripts/shots.py        # скриншоты всех страниц 390/1280 px в shots/ (нужен playwright)
python scripts/check_streams.py data/streams.json   # перепроверить онлайн-потоки (запускать с российского IP)
```

Онлайн-потоки: на сайт попадают только записи `data/streams.json` с `ok: true`. Поток считается
рабочим, если он по https и за 15 секунд реально пришло ≥32 КБ аудио (для HLS — скачался сегмент).
GitHub Actions раз в неделю пишет отчёт по потокам в лог, но сам ничего не удаляет.

## Варианты реализации

**1. Статический сайт на HTML/JS + JSON — выбран для MVP (сделан в этой папке).**
Страницы на чистом HTML/CSS/JS, данные в `data/*.json`, Python-скрипт превращает их в `site/data/*.js`.
Хостинг бесплатный (GitHub Pages, Netlify, Vercel), поддержка — правка JSON.
Плюсы: ноль зависимостей, быстрый, открывается офлайн. Минусы: SEO слабее, чем у сайта с
отдельными страницами под каждую станцию или антенну.

**2. Генератор статики (Astro / Eleventy / Hugo) + те же JSON.**
Отдельная страница на каждую станцию, антенну и процедуру («как включить SSB на D-808»),
sitemap, микроразметка. Это следующий шаг, когда нужен поисковый трафик. Данные и вёрстка
переносятся из MVP почти без изменений.

**3. Сайт + автообновление данных (cron-скрипты).**
Раз в сезон подтягивать расписание EiBi (CSV), раз в неделю — цены и наличие антенн через
публичные API маркетплейсов, проверять живость ссылок. Имеет смысл после запуска, если сайт
приносит трафик или партнёрский доход.

## Стек

- Фронтенд: HTML5, CSS (переменные, светлая и тёмная тема, адаптив от 360 px), ванильный JS без фреймворков.
- Данные: JSON в `data/`, скрипт `scripts/build_data.py` (Python 3.12, только стандартная библиотека).
- Проверка: Playwright (`scripts/shots.py`) — скриншоты и контроль горизонтального скролла.
- Для варианта 2: Astro или Eleventy. Для варианта 3: Python + cron + EiBi CSV + API Wildberries/Ozon.

## Риски

1. **Авторские права на иллюстрации инструкции.** Решение: свои схемы и фотографии своего экземпляра, текст своими словами.
2. **Данные устаревают.** КВ-расписания меняются в конце марта и в конце октября, FM-сетка — посезонно, цены и наличие антенн — еженедельно. Решение: дата сбора на страницах, метка «проверить», вариант 3.
3. **Точность расписаний.** EiBi — любительская база: передача может быть отменена, а станция по расписанию не слышна из-за прохождения. На сайте об этом сказано прямо.
4. **Версии приёмника отличаются.** Модификации 2018/2022/2023/2025 годов различаются прошивкой (шаг КВ 5 или 10 кГц, работа шумоподавителя, разъём USB). Спорные места помечены.
5. **Рейтинг антенн субъективен.** Честнее всего подтвердить его собственными замерами: SNR на экране D-808 по одной станции с каждой антенной. Это можно сделать, если купить 5–6 ключевых антенн.
6. **Схема панели условная.** Расположение кнопок на лицевой панели нарисовано приблизительно. Нужна сверка по фото реального приёмника.

## Оценка трудозатрат

|---|---|

| Вычитка и сверка данных человеком: частоты FM, расписания, ссылки на антенны | 4–6 ч |
| Фото своего экземпляра D-808, пошаговые фото «нажми сюда» для 10 ключевых процедур | 1 день |
| Замеры антенн (SNR на эталонных станциях) и уточнение рейтинга | 1–2 дня + покупка антенн |
| Вариант 2 (Astro, отдельные страницы, SEO, sitemap) | 2–3 дня |
| Вариант 3 (автообновление EiBi и цен) | 1–2 дня |
| Домен, хостинг, аналитика, партнёрские ссылки | 2–4 ч |
